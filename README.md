# MotorSpeedControl

RP2040-Zero で DC ギアードモータ（DFRobot FIT0403）を一定速度に保つファームウェアです。
FET による一方向 PWM 駆動と、エンコーダからのフィードバックによる PI 速度制御を行います。

## ハードウェア

| 部品 | 内容 |
|---|---|
| マイコン | Waveshare RP2040-Zero |
| モータ | DFRobot FIT0403（12V / 減速比 90:1 / 出力軸 122rpm / 2相エンコーダ付き） |
| ドライバ | ロジックレベル N-ch MOSFET（ローサイド）＋ フライバックダイオード |

### 配線

| RP2040-Zero | 接続先 |
|---|---|
| GP0 | FET ゲート（直列 100Ω 程度、ゲート-GND 間 10kΩ） |
| GP2 | エンコーダ A 相 |
| GP3 | エンコーダ B 相 |
| 3V3 | エンコーダ VCC |
| GND | エンコーダ GND、モータ電源 GND（共通） |
| GP16 | オンボード WS2812（状態表示） |

エンコーダは 3.3V 給電で動作し、A/B 相をマイコンに直結しています。

## 仕組み

- **PWM**: 20kHz、分解能 1000 段階
- **速度計測**: A/B 両エッジ割り込みで 4 逓倍カウント（出力軸 1 回転 = 16 × 4 × 90 = 5760 カウント）。10ms ごとの差分から rpm を算出し、ローパスフィルタで平滑化
- **制御**: 100Hz のフィードフォワード＋PI 制御（アンチワインドアップ付き）

ピン割り当て・ゲイン・エンコーダ方向（`ENC_REVERSE`）などの設定は [include/config.h](include/config.h) にまとめています。

## ビルドと書き込み

[PlatformIO](https://platformio.org/) を使います。

```sh
pio run                 # ビルド
pio run -t upload       # 書き込み（初回は BOOT ボタンを押しながら USB 接続）
pio device monitor      # シリアルモニタ（115200bps）
```

## シリアルコマンド

| コマンド | 内容 |
|---|---|
| `t <rpm>` | 目標回転数（出力軸 rpm、0〜122） |
| `s` | 停止 |
| `kp <値>` | 比例ゲインを設定 |
| `ki <値>` | 積分ゲインを設定 |
| `?` | ヘルプと現在のゲインを表示 |

テレメトリは 10Hz で `target:60.0 rpm:59.8 duty:52.3` の形式で出力され、シリアルプロッタでグラフ表示できます。

オンボード LED は、停止中が青、目標 ±5% 以内が緑、追従中が黄です。

## ファイル構成

```
include/config.h          設定（ピン、PWM、モータ定数、ゲイン）
src/main.cpp              制御ループ、シリアルコマンド、テレメトリ
src/motor.cpp             PWM 出力
src/encoder.cpp           エンコーダのカウント
src/speed_controller.cpp  FF + PI 速度制御
```
